#  COMP 584 - Homework 3

## The Reading Nook Email Campaign
This project is a responsive HTML email campaign for a bookstore called The Reading Nook.

### Features
- 600px single-column table layout
- Responsive hero image
- Background image behind promotional text
- Centered call-to-action button
- Mobile-responsive styling
- Accessibility testing using WAVE extension

### Accessibility Testing
The initial WAVE test, on Chrome extension, identified 1 error, 6 contrast errors, and 2 alerts.

After making corrections, the retest identified 0 errors, 3 contrast errors, and 1 alert.

Screenshots and the accessibility report are included in the assets folder.
